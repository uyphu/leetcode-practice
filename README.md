# 🧠 LeetCode Lessons Learned

Welcome to my personal repository where I document lessons, patterns, and key takeaways from solving LeetCode problems. This repo serves as both a learning journal and a reference to reinforce concepts and track progress.

---

## 📌 Why This Repo?

In technical interviews and real-world development, **problem-solving speed and clarity** are crucial. After struggling with time pressure and debugging during live coding sessions, I created this space to:

- Reflect on failed and solved problems.
- Identify recurring patterns.
- Improve speed, confidence, and accuracy.

---

## 📚 Structure

Each folder or markdown file includes:

- ✅ **Problem Summary**  
- 💡 **Approach & Thought Process**  
- 🧩 **Key Patterns** (e.g., Sliding Window, Two Pointers, DFS, etc.)  
- 🧠 **Lessons Learned** (e.g., bug fixes, missed edge cases)  
- 🚀 **Optimized Solution & Time Complexity**
